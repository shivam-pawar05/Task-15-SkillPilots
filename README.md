# Bookstore Database Management System

A MySQL project for managing authors, books, and sales.

## Tables
- authors: author details
- books: book details and stock
- sales: sales records

## Run
1. Start MySQL in XAMPP or open MySQL Workbench.
2. Execute `bookstore.sql`.
3. Inspect the authors, books, and sales tables.
4. Run individual examples from `database/queries.sql`.

Sample data: 3 authors, 5 books, and 5 sales records.
